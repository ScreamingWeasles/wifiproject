# Screaming Weasels Wi-Fi Teaser v0.7.1

Make Your Wi-Fi Squeal!

Built from the prior v0.7 source project. Changes:
- Pale grass-green Material 3 light theme on all tabs (#E4F0D7 background, #F7FBF3 surfaces, #326B37 accent).
- Scan tab toggle: By strength / By name A–Z (sorts BSSIDs by SSID; same-name APs remain individually visible).
- Join button on each non-connected BSSID row opens the Android system Wi-Fi panel (Android does not guarantee preselection of the tapped SSID).
- Connected BSSID remains identified in Scan; Wi-Fi tab's pinned connected graph remains unchanged.
- Version updated to 0.7.1.

Notes: This is source, not a compiled APK. The Gradle wrapper launcher/JAR are not included in the original project ZIP. If your working project has them, copy them into this project. Android Studio build/device testing is still required.
