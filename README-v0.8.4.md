# Screaming Weasels v0.8.4 — Dedicated scanning tabs

- Wi-Fi Scan: Wi-Fi SSIDs, BSSIDs, RSSI, sorting, Join, and channel analysis.
- Device Scan: IP Only, Gentle, Normal, Thorough, TCP services, UDP mDNS/SSDP listening, elapsed scan time, progress, Stop, and saved results.
- Changing the next scan mode no longer hides services from a previously saved Normal/Thorough scan.
- Device Scan and Wi-Fi Scan have separate navigation and results.
- No full packet capture: Android cannot observe arbitrary unicast streams between other devices.

Open OfficeWifiInspector in Android Studio and build/test on device. Not compiled in this environment.
