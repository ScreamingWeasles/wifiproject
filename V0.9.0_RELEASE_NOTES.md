# Screaming Weasels v0.9.0 — Development Source Preview

Based on v0.8.9 SALT Preview. Version code 15.

Implemented in source:
- Home first, with live compact current Wi-Fi information and navigation.
- About dialog displays version, while home and toolbar omit version.
- Survey accessible from AP Health, with detailed How to Use dialog.
- Speed Ping duration selector replaced by a slider including single-ping (1-second approximation) and until stopped.
- Device Scan adds separate Security Scan view of nearby Wi-Fi AP signals and existing LAN discovery.

NOT YET IMPLEMENTED / REQUIRES FURTHER DEVELOPMENT:
- Full survey timeline rendered into exported report and event timestamp markers.
- Global mustard-yellow pressed and selected state across all controls.
- Reliable camera classification (Wi-Fi identifiers cannot reliably prove surveillance hardware).
- A true single-ICMP-packet implementation; current slider's 1-second mode is approximate.
- Compilation and device testing were not performed in this environment.

Do not install the old app/build/intermediates/apk/debug/app-debug.apk: it belongs to the previous build.
Open in Android Studio and build a new APK after verifying the code.
