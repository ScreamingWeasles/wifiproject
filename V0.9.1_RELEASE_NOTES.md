# ScreamingWeasels v0.9.1 development source

Changes in this revision:
- Removed Floor Plan navigation and its UI branch.
- Replaced Home tool buttons with balanced two-column square tiles; Wi-Fi summary stays on top.
- Reduced navigation label text size and added truncation for narrow screens.
- Added animated Signal Hunter radar-style sweep, AP selection, current RSSI, channel and comparative stronger/weaker indication.
- Retained previous baseline comparison and classification controls.
- Updated versionName to 0.9.1, versionCode to 16.

IMPORTANT: Radar sweep is a visualization, NOT an actual angle or distance measurement.
Not yet implemented: radar audio cues, automated notifications, complete trace route, full survey chart PDF export, persistent alert history, and global pressed-state styling.
This source has not been compiled or device-tested. Do not install any APK from the old build directory.
